# UI design

The visual system uses a restrained teal primary color, neutral surfaces, clear semantic colors, and centralized tokens in `lib/core/theme/`. Light and dark themes share component styling and follow system appearance by default; Settings also allows a session-level override.

Layouts use flexible lists, wraps, and available-width sizing. Expense cards preserve long merchant names with ellipsis and keep amounts visible. Scan review keeps the receipt image and editable fields together. Empty and error states provide a useful next action where possible. Reports charts are custom-painted and animate as presentation concerns in their widgets.
